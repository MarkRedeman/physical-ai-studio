# Exporting Datasets

Use dataset export when you want to back up or move dataset content.

## Where users export in the UI
[//]: # (Screenshot suggestion: dataset tab action menu with Export dataset item highlighted.)

In Datasets:

1. Open the dataset tab.
2. Open dataset actions.
3. Click Export dataset.

The app opens a download flow and prepares a ZIP archive.

## What users see during export
[//]: # (Screenshot suggestion: dataset export progress dialog and browser download start notification.)

- A progress dialog while the archive is prepared/downloaded.
- A browser file download when ready.
- Error feedback if export fails.

## User tips
[//]: # (Screenshot suggestion: downloaded ZIP file in file manager with meaningful dataset-based filename.)

- Keep the browser tab open until the download begins.
- Use clear dataset names so downloaded ZIP files are easy to identify.
- Export before destructive cleanup actions.

## After export
[//]: # (Screenshot suggestion: optional screenshot of exported archive ready for transfer or backup location.)

Users often:

- Share the archive with teammates.
- Import the archive into another setup.
- Keep it as an experiment snapshot.
