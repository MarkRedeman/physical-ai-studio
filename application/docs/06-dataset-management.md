# Dataset Management

Use the Datasets area to organize, review, and clean up your collected data.

## Dataset tabs and actions
[//]: # (Screenshot suggestion: Datasets tab row with one dataset selected and tab action menu open showing Edit name / Export / Delete.)

Each dataset appears as a tab. From the tab actions menu, users can:

- Edit dataset name
- Export dataset
- Delete dataset

You can also add/import datasets from the add menu.

## Open and review datasets
[//]: # (Screenshot suggestion: dataset detail view with episode list and preview panel.)

When you open a dataset, the UI lets you:

- Browse episodes.
- Inspect visual playback/frames.
- Check if the dataset matches the intended task.

Use this review step before training.

## Rename datasets
[//]: # (Screenshot suggestion: rename dataset dialog with current and edited dataset name.)

Use Edit dataset name when:

- A name is too generic.
- You want clearer versioning for experiments.

Keep names easy to scan in tabs and model-training pickers.

## Delete datasets safely
[//]: # (Screenshot suggestion: delete dataset confirmation dialog showing optional "remove files from disk" checkbox.)

Delete dialogs can include an option to also remove files from disk.

Before confirming delete:

- Make sure the dataset is not needed for active experiments.
- Export first if you need a backup.
