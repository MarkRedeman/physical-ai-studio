# Deploying Model Policies

In the current UI, users deploy a model by running it in the inference flow.

## Start deployment from Models
[//]: # (Screenshot suggestion: model actions menu with Run model selected, followed by backend selection dialog.)

On a trained model:

1. Open model actions.
2. Click Run model.
3. Select a backend.
4. Click Start.

This opens the inference view.

## What users see in inference view
[//]: # (Screenshot suggestion: inference view showing model/environment readiness indicators and start/stop controls.)

Users can:

- Confirm model/environment readiness.
- Start and stop model-driven execution.
- Observe robot and camera panels while the model runs.

## Typical user checks before starting
[//]: # (Screenshot suggestion: inference setup state where selected environment and connected hardware are visible.)

- Correct environment is loaded.
- Hardware is connected and stable.
- Workspace is safe for robot movement.
