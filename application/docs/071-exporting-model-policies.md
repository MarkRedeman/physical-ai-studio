# Exporting Model Policies

This chapter covers user-facing model export/download behavior in the UI.

## Where users export models
[//]: # (Screenshot suggestion: model row actions menu with Download selected.)

In Models:

1. Open model actions.
2. Click Download.

The download dialog opens.

## What users can choose
[//]: # (Screenshot suggestion: Download model dialog showing "Include training dataset snapshot" checkbox and Download button.)

Before starting the download, users can choose whether to:

- Include training dataset snapshot.
- Download model only.

Then click Download.

## What users see during export
[//]: # (Screenshot suggestion: download progress/preparing state and browser download prompt.)

- A preparing/progress state.
- A browser download when ready.
- Error message if export fails.

Users can cancel while download is in progress.

## When to include snapshot
[//]: # (Screenshot suggestion: optional comparison visual of small model-only archive vs larger archive with snapshot.)

From a user perspective:

- Include snapshot when sharing a fully reproducible package.
- Skip snapshot for smaller downloads.
